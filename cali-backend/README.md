# Cali Backend (previsto)

Este directorio está reservado para un servicio independiente con NestJS y TypeScript. Todavía no se ha inicializado el backend.

El servicio previsto gestionará autenticación, usuarios, sesiones de agentes, políticas financieras, presupuestos y límites de gasto, integración x402, solicitudes de autorización, historial de transacciones y notificaciones WebSocket. Se prevén PostgreSQL y Prisma para datos, además de Solana Kit y el SDK oficial de x402 Foundation para cadena y pagos.

Consulta la [arquitectura](../docs/architecture.md) para conocer los límites entre componentes.
