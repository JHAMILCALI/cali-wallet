# Cali MCP (previsto)

Este directorio está reservado para un servidor independiente con Node.js, TypeScript y el SDK oficial de Model Context Protocol. Todavía no se ha implementado el servidor MCP.

Las herramientas previstas permitirán a agentes autenticados consultar balances y presupuestos, solicitar pagos x402 y verificar transacciones mediante Cali Backend. El servidor MCP no custodiará las claves privadas de la wallet móvil.

Consulta la [arquitectura](../docs/architecture.md) para conocer los límites entre componentes.
